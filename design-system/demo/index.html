这些 demo 遵守的硬约束

  • 数据真实性：价格、销量、车系参数、评价、联系方式全部抓取自生产站， 无编造。拿不到真数据的字段一律留空并显式标注，不用示例值填充。
  • 品牌色以真实渲染为准：主色 #FFCF20 取自生产 DOM 的 bg-ffcf20，不是框架预置色板。详见 AGENTS.md Step 2.5。
  • 不画假曲线：车系页「Tendencia precio promedio」在 stable 只有 1 个真实点位 （其余 0 次咨询），因此只渲染该点并显式标注缺口，不补示意曲线。
  • MX 合规：触达仅 WhatsApp（页面内无「微信」），留资表单 CTA 下必带 Aviso de Privacidad 与中介免责。
  • 无后端：只有单文件 HTML + CSS 变量 + Iconify CDN； 表单与筛选均为前端模拟，不真提交、不写任何 API。
