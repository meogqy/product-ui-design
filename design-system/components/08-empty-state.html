🎯 使用规则

  • 无数据：首次访问 / 用户还没填内容 / 数据库为空
  • 无结果：搜索 / 筛选后没有命中，给出"清空筛选 / 重置搜索"选项
  • 错误：加载失败 / 网络异常 / 服务端错误，提供"重试"按钮
  • 插画：建议替换为产品专属插画（`components/` 内可能有），不要只用通用 icon
  • 文案：标题 1 句话讲清，描述给下一步行动建议，不要用"出错了"
  • CTA：必须有至少 1 个，下一步是什么很清楚
  • ARIA：加 role="status" 或 role="alert"（错误时）
