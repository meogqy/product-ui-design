🎯 何时用哪种配置

  • Title=true：表单字段（姓名 / 电话 / 邮箱 等需要明确标识的字段）
  • Title=false：搜索框 / 短输入（标题隐含在 placeholder 里）
  • 已填写=true（蓝底 #E6EEFF）：用户已输入内容，标识为"激活态"
  • 已填写=false（灰底 #F8F8F8）：占位状态，等待输入
  • 必填字段：Title 后加 * 红色星号（Red/red-500-告警）
