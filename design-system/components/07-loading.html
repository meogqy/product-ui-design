🎯 使用规则

  • 异步加载时：任何 fetch / API / 资源加载期间显示
  • 避免布局抖动：骨架尺寸必须跟真实元素一致（height / width / gap 都要对）
  • 不要做"装饰"：只在真正加载时才显示，加载完立刻移除
  • 不要过长时间：超过 5 秒应显示 Error State 或 Toast 提示
  • 页面骨架：首屏加载用，避免白屏
  • ARIA：加 aria-busy="true" 让屏幕阅读器知道在加载
