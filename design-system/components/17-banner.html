🎯 使用规则

  • Info：系统公告 / 维护通知 / 重要提示
  • Promo：营销活动 / 优惠码 / 限时优惠
  • Warning：必读风险 / 验证提示 / 合规警告
  • 位置：通常在页面顶部 / 列表上方 / 表单顶部
  • 可关闭：除 warning 外都可以让用户关闭
  • 不要用 Banner：瞬态消息用 Toast，阻断操作用 Modal
  • ARIA：info / promo → role="status"；warning → role="alert"
  • 每次只 1 个：不要堆叠多个 banner（按优先级放最重要的）
