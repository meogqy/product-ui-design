⚠️ 注意事项

  • ✅ 所有按钮颜色 / 字号 / 圆角 必须用 token，禁止硬编码 hex
  • ✅ Disable 用浅灰底 + 灰字（#F1F1F1 + #999999），保持可识别但不可点
  • ✅ Disable-2 用品牌色 + opacity 0.5（区别于 disable，用于"已选 / 不可重复"等场景）
  • ❌ 禁止用 Yellow 按钮做金融 / 信用相关（金融场景必须用 Blue）
  • ❌ 禁止移动端用 Size 48（间距太大）或 PC 端用 Size 44（视觉太弱）
  • ❌ 禁止添加 box-shadow / 渐变 / outline（本组件设计就是纯静态）
